Allocated dispatch-tail experiment

Passed: eight dedicated tests and two existing regressions, including native ARM execution. Bounded explicit opt-in; default selection tiers and Fast output remain unchanged. No runtime performance claims.

Enable with ExperimentalDispatchTails(&selector) as the pipeline selector. No allocator policy or CLI changes are required.

The emitter replays the original Jump edge copies followed by the original Switch allocation events and operand locations. Only emitted assembly identities differ. Shared block parameters keep their allocated homes for direct downstream uses.

Limits: 4–128 dense cases, at most eight copies and 1,024 added table entries per function. Inline assembly, debug metadata, custom constraints and unsupported terminator events reject the experiment. Bounds checks, default traps, all case edges and the original switch remain.

The independent native oracle exercises every case, both branch routes, ordinary and forced-spill allocation, combined edge/phi cycles, default holes and 32/64-bit out-of-range keys. Text and structured emitters produce identical object bytes.

# Assembler and linker benchmarks (2026-11-05)

Command-line assembly and link times of Keel `8226e95c`, a release build with
Rust 1.99.1. Commands, input hashes and every sample are in
[assembly-link-20261105.json](assembly-link-20261105.json).

| | |
| --- | --- |
| Machine | Apple M5 Max, macOS 27.0.1, SDK 27.0 |
| References | Apple Clang 21.0.0, Apple `ld-27037.1` |
| Protocol | 2 warmups, 7 measured runs, median; shuffled order per round; load average 2.6 |
| Input | [`runtime-kernels.c`](../../crates/keel/tests/fixtures/runtime-kernels.c) and [`driver.c`](../../suite/linker/fixtures/driver.c) |

The runner targets Apple arm64 only. No tracked runner measures assembly or
linking on x86-64 Linux, so this page has no AMD Zen 5 results.

## Results

| Stage | Keel | Apple tool | Clang driver |
| --- | ---: | ---: | ---: |
| Assemble two `.s` files → two `.o` | 6.18 ms | `clang -cc1as`: 17.26 ms | `clang -c`: 23.49 ms |
| Link two `.o` → signed executable | 16.73 ms | `ld`: 14.69 ms | `clang`: 22.38 ms |

Each sample is whole-process wall time, including startup and file I/O.
The assembly inputs are the two files generated by `clang -S -O0` (35,748
bytes total), and every assembler and linker consumes identical inputs. Keel's
link reads the SDK `.tbd` interfaces, signs the executable ad hoc, and syncs
the output file and its directory to disk before it returns.

## Correctness gate

Before timing:

- Every assembler's `__TEXT,__text` bytes and relocations match Clang's.
- All six resulting executables pass 12 kernels × 4 input lengths against an
  independent Python oracle (288 checks) and `codesign --verify --strict`.

Clang `-O2` output is not used, because Keel's assembler rejects the
`sabd.4s` mnemonic form it contains.

## Reproduce

On Apple arm64 macOS:

```sh
cargo build --release -p keel
python3 suite/linker/run.py --keel "$PWD/target/release/keel" --out bench-out
```

`--out` must be a new directory. Add `--correctness-only` to run the gate
without timing. Inputs are small, so process startup is a large share of each
time. This does not measure throughput on large projects.

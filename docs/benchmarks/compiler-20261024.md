# Compiler benchmarks (2026-10-24)

Compile-time measurements behind the README charts. Every sample, command,
input hash and stage timer is in [compiler-20261024.json](compiler-20261024.json).

| | |
| --- | --- |
| Machine | Apple M5 Max (18 CPUs, 128 GiB), macOS 27.0.1 |
| Keel | `2cd51766`, release build, Rust 1.99.1 |
| References | Apple Clang 21.0.0, Cranelift 0.136.3 |
| Protocol | 2 warmups, 7 measured runs, median; configuration order varied each round |
| Input | [`kernels.c`](../../crates/keel-cranelift/kernels/kernels.c): one header-free TU, 31 functions |

## C source → object file

Whole-process wall time: startup, frontend, optimization, code generation,
assembly and object writing. No linking.

| Configuration | Median |
| --- | ---: |
| `keel cc --emit-object` | 4.32 ms |
| `keel cc -O --emit-object` | 5.35 ms |
| `clang -O0 -c` | 16.82 ms |
| `clang -O2 -c` | 41.78 ms |

Clang runs with `-ffp-contract=off`. Keel `-O` and Clang `-O2` are different
pipelines; the comparison is of configured compile time, not equal work.

## Keel IR → object file

The same parsed and verified Keel IR is fed to Keel's native backend and to
Cranelift (through the `keel-cranelift` bridge), in process. Times are the sum
of backend stages; parsing, IR optimization, startup and file I/O are excluded.

| Input IR | Keel baseline | Keel full | Cranelift `none` | Cranelift `speed` |
| --- | ---: | ---: | ---: | ---: |
| Unoptimized | 377 µs | 413 µs | 775 µs | 1011 µs |
| Optimized by Keel `-O` | 382 µs | 412 µs | 783 µs | 1106 µs |

"Baseline" and "full" are Keel's instruction-selection levels; Cranelift
`none`/`speed` are its `opt_level` settings. Keel objects include unwind info;
the bridge emits none.

## Correctness gate

Timing only runs after every configuration passes. All 12 builds (4 C, 8 IR)
link against [`driver.c`](../../crates/keel-cranelift/kernels/driver.c) and
must print the same 795 lines as Clang. Timed outputs are checked against the
gated objects' hashes.

## Reproduce

On Apple arm64 macOS:

```sh
cargo build --release -p keel
cargo build --release --manifest-path crates/keel-cranelift/Cargo.toml \
  --bin keel-cranelift --bin keel-cranelift-bench
python3 suite/readme-bench/compiler.py --out bench-out \
  --keel target/release/keel \
  --bench crates/keel-cranelift/target/release/keel-cranelift-bench
python3 suite/readme-bench/publish.py bench-out/report.json compiler.json
```

Add `--correctness-only` to `compiler.py` to run the gate without timing.
Results are a single-machine sample on a small input, not a general speed
ratio.

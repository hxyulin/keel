# Compiler benchmarks (2026-11-05)

Compile-time measurements of Keel `8226e95c`, a release build with Rust
1.99.1. Every sample, command, input hash, stage timer and per-object
instruction count is in [compiler-20261105.json](compiler-20261105.json).

Retired instructions are the compile-time metric of the
[performance guide](../development/performance.md), and they are recorded on
both acceptance hosts. The wall-time comparisons with Clang and Cranelift run
on the Apple M5 Max only, because their runner targets Apple arm64.

## Retired instructions on the suite corpus

`cargo suite codegen-diff --icount` compiles every suite translation unit to
assembly for the host target and counts each compile's retired instructions.
The run passes the same binary as baseline and candidate, so each total below
is two runs of one compiler.

| Host | Target | Translation units | `keel` | `keel -O` |
| --- | --- | ---: | ---: | ---: |
| Apple M5 Max, macOS 27.0.1 | `aarch64-apple-darwin` | 79 | 25.15 and 25.14 billion | 39.88 and 39.83 billion |
| AMD Zen 5 desktop, Linux 7.3 | `x86_64-unknown-linux-gnu` | 79 | 19.11 and 19.11 billion | 34.09 and 34.08 billion |

macOS counts the whole process with `/usr/bin/time -l`. Linux counts user
mode with `perf stat -e instructions:u`. The two runs differ by at most 0.12%.
The counts include process startup, preprocessing and assembly output, and
they are not comparable across hosts.

## C source → object file

On the Apple M5 Max (18 CPUs, 128 GiB), with Apple Clang 21.0.0 as the
reference. Whole-process wall time covers startup, frontend, optimization,
code generation, assembly and object writing, but no linking. The input is
[`kernels.c`](../../crates/keel-cranelift/kernels/kernels.c), one header-free
translation unit with 31 functions. Each configuration had 2 warmups and 7
measured runs, with the order shuffled each round. The load average was 3.7.

| Configuration | Median |
| --- | ---: |
| `keel cc --emit-object` | 4.58 ms |
| `keel cc -O --emit-object` | 6.07 ms |
| `clang -O0 -c` | 16.19 ms |
| `clang -O2 -c` | 41.15 ms |

Clang runs with `-ffp-contract=off`. Keel `-O` and Clang `-O2` are different
pipelines, so this compares configured compile time, not equal work.

## Keel IR → object file

The same parsed and verified Keel IR goes to Keel's native backend and to
Cranelift 0.136.3 through the `keel-cranelift` bridge, in process. Times are
the sum of backend stages. Parsing, IR optimization, startup and file I/O are
excluded.

| Input IR | Keel baseline | Keel full | Cranelift `none` | Cranelift `speed` |
| --- | ---: | ---: | ---: | ---: |
| Unoptimized | 415 µs | 474 µs | 765 µs | 1040 µs |
| Optimized by Keel `-O` | 400 µs | 454 µs | 782 µs | 1061 µs |

"Baseline" and "full" are Keel's instruction-selection levels. Cranelift
`none` and `speed` are its `opt_level` settings. Keel objects include unwind
info, and the bridge emits none.

## Correctness gate

Timing runs only after every configuration passes. All 12 builds (4 from C, 8
from IR) link against [`driver.c`](../../crates/keel-cranelift/kernels/driver.c)
and must print the same 795 lines as Clang. Timed outputs are checked against
the gated objects' hashes.

## Reproduce

Retired instructions, on either host:

```sh
cargo build --release -p keel
cargo suite codegen-diff --baseline target/release/keel --candidate target/release/keel \
  --target aarch64 --icount --expect-identical   # --target x86_64 on x86-64 Linux
```

Wall time, on Apple arm64 macOS:

```sh
cargo build --release -p keel
cargo build --release --manifest-path crates/keel-cranelift/Cargo.toml \
  --bin keel-cranelift --bin keel-cranelift-bench
python3 suite/integration/compiler-bench/compiler.py --out bench-out \
  --keel target/release/keel \
  --bench crates/keel-cranelift/target/release/keel-cranelift-bench
python3 suite/integration/compiler-bench/publish.py bench-out/report.json compiler.json
```

Add `--correctness-only` to `compiler.py` to run the gate without timing.
The wall times are a single-machine sample on a small input, not a general
speed ratio.

# Runtime benchmarks (2026-10-22)

How fast programs compiled by Keel run, compared with Clang. Per-workload
timings, ratios and confidence intervals are in
[runtime-20261022.json](runtime-20261022.json).

| | |
| --- | --- |
| Machine | Apple M5 Max, macOS 27 |
| Keel | `7b72d98b`, `keel cc -O` |
| Reference | Apple Clang 21.0.0 `-O2` |
| Protocol | 7 paired rounds; median of paired Keel/Clang time ratios |
| Applications | Lua, SQLite, LZ4, yyjson, QuickJS ([suite](../../suite/README.md)) |

## Results

Ratio is Keel time ÷ Clang time, so above 1 means the Keel build is slower.

| Application | Workload | Keel `-O` | Clang `-O2` | Ratio |
| --- | --- | ---: | ---: | ---: |
| Lua | fib | 79.3 ms | 54.2 ms | 1.46× |
| Lua | sort | 66.5 ms | 55.0 ms | 1.21× |
| Lua | string | 96.6 ms | 75.4 ms | 1.28× |
| Lua | float | 220.7 ms | 157.1 ms | 1.41× |
| SQLite | queries | 367.0 ms | 243.4 ms | 1.48× |
| LZ4 | compress | 47.5 ms | 30.0 ms | 1.58× |
| LZ4 | decompress | 21.8 ms | 15.6 ms | 1.41× |
| yyjson | api | 82.6 ms | 46.3 ms | 1.79× |
| yyjson | config | 30.4 ms | 17.6 ms | 1.72× |
| yyjson | telemetry | 47.3 ms | 31.7 ms | 1.50× |
| QuickJS | fib | 71.7 ms | 39.1 ms | 1.83× |
| QuickJS | sort | 223.8 ms | 112.3 ms | 1.99× |
| QuickJS | string | 499.0 ms | 277.6 ms | 1.84× |

Per application (geometric mean over its workloads): Lua 1.34×, SQLite 1.48×,
LZ4 1.49×, yyjson 1.66×, QuickJS 1.89×. Overall: **1.56×**.

Times are whole-process wall time, including startup. Both compilers build
from the same Clang-preprocessed sources, and benchmark outputs must match
before timing. The ratios in the table are medians of the paired per-round
ratios, so they can differ slightly from the ratio of the median times.

## Reproduce

```sh
cargo build --release -p keel
cargo suite run -c clang-O2,keel-O
```

See the [suite guide](../../suite/README.md) for workloads and configurations.

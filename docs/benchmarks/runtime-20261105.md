# Runtime benchmarks (2026-11-05)

How fast programs compiled by Keel run, compared with Clang, on the two
acceptance hosts of the [performance guide](../development/performance.md).
Per-round samples, paired ratios, identical-binary controls and binary hashes
are in [runtime-20261105.json](runtime-20261105.json).

| | Apple M5 Max | AMD Zen 5 |
| --- | --- | --- |
| Machine | Apple M5 Max, macOS 27.0.1 | AMD Zen 5 desktop, Linux 7.3 |
| Target | `aarch64-apple-darwin` | `x86_64-unknown-linux-gnu` |
| Reference | Apple Clang 21.0.0 `-O2` | Clang 23.1.4 `-O2` |
| Keel | `8226e95c`, `keel cc -O` | `8226e95c`, `keel cc -O` |
| Load average at start | 1.3 | 0.2 |

Both hosts ran 7 rounds with one warmup. Configurations rotate each round, and
the rotations reverse every other round. Applications are Lua, SQLite, LZ4,
yyjson, QuickJS and Zstd ([suite](../../suite/README.md)).

Geometric mean over each application's workloads:

| Host | Lua | SQLite | LZ4 | yyjson | QuickJS | Zstd | Overall |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Apple M5 Max | 1.22× | 1.35× | 1.49× | 1.65× | 1.44× | 1.15× | **1.37×** |
| AMD Zen 5 | 1.33× | 1.36× | 1.18× | 1.25× | 1.88× | 1.21× | **1.35×** |

The overall value is the geometric mean of the six application values.

Times are whole-process wall time, including startup. Each compiler
preprocesses the same sources itself, and benchmark outputs must match before
timing. The ratios are medians of the paired per-round ratios, so they can
differ slightly from the ratio of the median times. Each run also times a copy
of the Clang executable as an identical-binary control. The largest control
deviation is 4.1% on the M5 Max (QuickJS string) and 3.6% on Zen 5 (Lua
string). Read single-workload differences smaller than that as noise.

This is a baseline for the current compiler, not an A/B test. Decide a
compiler change with `cargo suite ab`, as the
[performance guide](../development/performance.md) describes.

## Reproduce

```sh
cargo build --release -p keel
cargo suite run -c clang-O2,keel-O -n 7
```

Results are saved under `target/keel-suite/results/<target>/`. See the
[suite guide](../../suite/README.md) for workloads and configurations.

Call load reuse

Opt-in bounded reuse across body-proven no-memory direct leaves and agreeing CFG joins. Defaults and universal memory barriers are unchanged.

Supported contract

A uniquely named local or explicitly noninterposable direct definition, matching the call-table Signature exactly, has one block, at most 128 instructions and 512 values. No variadic, returns_twice, noreturn, debug homes, function source location or located instruction.

Accepted leaf bodies contain only integer constants/comparisons/selects, integer extend/truncate, wrapping integer add/subtract/multiply/bitwise/shifts/pointer addition and return. No memory access, writes, capture into memory, calls, recursion, floating environment effects, division/traps, assembly, frame observation, stack lifetime operation, exception or nonlocal flow.

This is a no-memory body proof and a no-persistent-capture proof for all operands inside that body. Operands and derived pointers may be returned. There is no general capture analysis and no exported nonescape assumption.

Unknown, interposable, indirect, recursive and invoke calls invalidate availability. All writes, volatile/atomic operations, intrinsics, assembly and unrecognized operations invalidate. FrameAddress anywhere rejects the caller; caller returns_twice or debug homes/function location reject it. Located instructions clear facts and cannot supply or consume them.

Safety proof and consumer

Only call-load-reuse consumes its invocation-local summary map. It exports no FunctionAttrs, nocapture promise, or alias facts to other passes.

Availability contains only the result of an earlier successful ordinary read, keyed by the exact resolved address SSA value and exact type. Stale redirected load definitions cannot supply a fact. There is no store forwarding, address algebra, alias-derived independence, or change to universal memory effects.

The first successful read and every call stay pinned. Deleting a later equal read cannot introduce a speculative access or change read-before-fault order: the same address/type was already successfully read and no intervening admitted operation can change its contents or lifetime. Trapping scalar operations and all unsupported effects discard availability.

An accepted leaf cannot access even previously captured memory, because it cannot access memory at all. Returning a pointer is allowed; a subsequent store through it is still a barrier. No argument-specific capture shortcut or ABI-based nocapture inference is used.

RPO snapshots carry at most 128 facts and eight edges. A join requires completed states for every predecessor and retains only identical address/type/value facts. Each retained value therefore dominates all incoming paths and the replacement. Missing/backedge states discard all facts; there is no loop fixed point, phi translation, or block-argument translation.

Caller budgets are 50000 instructions and 100000 values. Instruction count is checked before the whole-function observer scan. Callee block checking stops after two blocks. Fact copying and join intersections are capped at 128 facts; edge depth is the maximum incoming depth. Cap exhaustion loses facts conservatively.

Limits

Single-block no-memory leaf subset only; no recursive/transitive read-only/write-region summaries.

Exact address SSA identity only; no new alias framework or MemorySSA.

The full projects were statically transformed, not natively linked or executed in this child. Root owns paired project measurements.

Runtime DYLD interposition was not validated successfully; link-time mutating substitution was.

# Controlled aggregate helper reserve (research only)

`inline-aggregate-reserve` is an explicit replacement for `inline` in a named
pipeline. No optimization tier includes it. Do not append it after `inline`:
that would run a second independent inlining invocation and change the experiment.
Production `inline`, thresholds and tier pipelines are unchanged.

This experiment tests whether the ordinary clone path can activate the original
QuickJS helper site. It does not select a symbol, workload, opcode, ordinal,
profile or instruction identity. Small call-free aggregate helpers are the
structural domain: sret and at least one byval <=16 bytes, <=4 blocks, <=64 new
declared stack bytes, conservative raw net layout cost <=32. Existing eligibility,
profitability, exact signature, recursion, returns_twice, exception, byval,
restrict, debug and multiple-result contracts still apply. Intrinsics and calls
are excluded from the reserve domain. Default successful sites use the normal
ledgers. Only an instruction-budget failure can use the reserve.

The separate reserve allows at most eight sites/caller and eight/module: worst-case
256 extra layout instructions/caller and 256/module, beyond ordinary 2048/16384.
These are explicit experimental hard bounds, not a refund or blanket increase to
production caps. Shared 128-call and 65536-byte new-stack limits still apply.
Every actual reserve delta is measured immediately after cloning, checked <= its
conservative preflight cost <=32 and reported as `experimental_net_growth`.
Unused/unreachable callee instructions remain conservatively charged. No cleanup
savings are assumed. Each invocation is bounded independently, like ordinary
inline; experiment drivers must run exactly one replacement invocation.

32 is a small growth ceiling admitting the measured raw helper cost31 (23 body
instructions plus8 snapshot instructions). Eight sites is a finite exploration
batch, not a hotness prediction; this tests multiple sites and must not inherit
the manually isolated one-site performance result. All added, lost and displaced
choices and actual application growth must be recorded. Subsequent cleanup can
change the whole module; exact machine-code parity with the manual artifact is
not assumed. Root reviews source and activation before any timing or integration.

Rejection leaves the caller untouched using existing preflight checks. Commit
uses the unchanged `inline_call`, with its established snapshot/import/debug/SSA
remapping. There is no recoverable fallback after mutation: an unexpected growth
violation aborts compilation before an artifact, rather than exporting a partial
rollback. No Function print/reparse or new clone alias map is used for admission.

Historical private transactional planner is not imported. Its R1 derived
borrowed-slot live-in alias failure and R2 exact-root fix remain historical
receipts, not disproved or resurrected here. That planner had zero actual
QuickJS commits under its caps/guards. The historical frontend-vs-parsed raw
phase mismatch also remains real. New baseline/candidate must be generated by
this exact compiler from the same retained Linux preprocessed source and target;
ARM native correctness cannot qualify x86 native execution.

Initial tests: existing inline integration suite plus actual reserve cloning,
measured growth, per-caller/module finite exhaustion, explicit-only registration,
noinline and nonaggregate negative controls. Actual Linux application activation,
codegen/native oracles, full portable checks, current compile cost and runtime
remain distinct gates; no benchmark of identical binaries is permitted.

Initial b85922f source used a 32-site module ceiling. The fresh actual activation
probe observed 32 additional expansions across14callers (992 instructions).
Before codegen/native/timing, the global ceiling was reduced to one eight-site
batch (256 instructions) to keep this application experiment narrow. This is an
explicit source refinement, not a favorable runtime selection or a claim that
eight sites are profitable. Initial source/activation receipts remain retained.

What changed

Eligible private ARM integer leaves allocate directly in x0–x7. ARM and x86 leaves with no frame requirements omit their frame. The opt-in private-call pass now includes safe word-sized helpers as well as narrow arguments.

TLS getters, calls, stack observers, debug modules, incoming stack arguments and save/spill requirements retain conservative handling. Custom register pools remain respected. The call ABI still uses the existing save rules.

Correctness and limits

876 tests passed, 0 failed, 2 ignored in the final optimizer/codegen run. Native ARM checks cover eight call configurations, four multithreaded TLS configurations and four high-pressure configurations. The importer gate passed all 54 checks. All five application correctness gates passed.

All 48 unchanged-Full application objects match the prior frozen baseline byte for byte. Independent review found and resolved a TLS clobber defect, then reported no remaining concrete defect.

Native x86 execution, deterministic entry-copy cycle coverage and actual runtime unwinding remain unvalidated. Shared Clang-preprocessed C and a common link are used; timings include process startup. One compile round per boundary is retained in the evidence and supports no stable compile-speed claim.

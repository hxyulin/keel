What the measurements support

Normal Full: LZ4 decompression improves about 1.6%, with a repeat at 2.0%. The other workloads are broadly unchanged at this screen’s resolution. A borderline QuickJS string slowdown did not reproduce in a 15-round follow-up with an identical-binary control.

Scheduling: Earlier cleanup improves yyjson by roughly 9–12%, but regresses Lua fib by 10%, QuickJS fib by 37% and QuickJS sort by 24%. The same early schedule on the frozen compiler produces most of the yyjson benefit, so it cannot be credited uniquely to the new pointer facts. No schedule is promoted.

Static code is supporting evidence: late cleanup reduces yyjson visit from 675 to 595 instructions but runs slower. Earlier cleanup emits 694 instructions and improves the complete yyjson workload. Function instruction counts alone do not explain application runtime.

C++ compatibility checkpoint

Exact [2 x i64] parameters now use one ptr byval {i64, i64}, preserving aggregate register exhaustion and stack placement. Native tests cover callbacks, mutated lane values, register/stack boundaries and std::string_view. Unsupported aggregate forms still reject.

The untouched pugixml application advances to llvm.memcpy.p0.p0.i64 ABI-attribute rejection. Application tiers remain unreached; broader C++ support is still incomplete.

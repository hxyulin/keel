Recommended next change

Keep the address simplification and constructor priority. Refine the inlining budget so late callers can still inline bounded, cheap predicates and wrappers. Use structural cost and bounded reserves rather than QuickJS-specific names; check the constructor wins and sorting together.

There is no evidence here that another instruction-selection change is the first fix. Extra aggregate copies around the remaining calls are a secondary opportunity.

Validation and limits

Both isolated compiler variants and both assembly-experiment variants passed all nine QuickJS application tests and matching fib/sort/string outputs. The initial 25-round repeat included byte-identical executable copies; it still leaned slower but had more scatter.

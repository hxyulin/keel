Bounded private-field promotion: explicit opt-in

Proofs and growth limits

Escape and overlap checks stay per object. Escaped slots cannot exhaust useful-field selection. Backward liveness limits parameter placement; initialization remains a separate must proof. Unsupported aliases, partial initialization, nonuniform wider stores, debug homes, frame observers and exceptional/nonlocal continuations retain their barriers.

Validation

506 optimizer tests pass across 61 targets, including nine dedicated tests and the 16 existing promotion tests. Coverage includes joins, duplicate edges, loops, zero trips, unreachable predecessors, partial coverage, alias substitution, escapes, many fields, source locations and bounded parameter growth. Every Cargo/compiler/formatter command ran under the shared lock with a checkout-local Cargo target.

No native correctness or performance claim. Root owns paired measurements. Legal fields may remain in memory when budgets are exhausted; SSA placement is live-in pruned, not minimal dominance-frontier construction.

How to interpret this run

Nine paired runtime rounds after two warmups, randomized interleaving, exact output checks, one ARM host and one linked layout per configuration. Shared performance lock held during measurement.

Byte-identical Clang-copy control medians ranged from -5.6% to +5.6%. Confidence intervals describe this campaign, not variation across hosts/layouts. Near-zero differences should stay inconclusive.

No defaults were promoted. These are useful bounded candidates; the table shows where each helps or hurts. The small no-memory leaf proof is a first step toward wider call/memory analysis, and aggregate elimination still excludes escaping or observed homes.

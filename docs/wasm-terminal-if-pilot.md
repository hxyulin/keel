## Selection and emission contract

Selection occurs after the existing complete original-input admission. It
requires exactly three layout blocks, with entry first, an entry Brif to two
distinct remaining blocks, no arm parameters or edge arguments, and an ordinary
Return at each arm's end. Earlier terminators reject selection. An additional
resolved-operand availability scan requires every read to refer to an entry
parameter, an earlier entry definition, or an earlier definition in the same
arm. It introduces no cross-arm transport. Removed blocks do not count; extra
laid-out blocks prevent selection. The existing verifier still rejects invalid
or nondominating input rather than passing it to a permissive fallback.

Emission visits entry, true arm, false arm, regardless of the relative layout
order of the arms. It emits an empty-typed MVP if/else and the existing arm
instructions and Return emitter. Only the selected arm executes. A final
unreachable supplies the function's unreachable continuation after the
empty-typed if; this preserves MVP result typing without a result transport
scheme. The PC local, PC comparisons, dispatch loop and edges are omitted only
for the exact eligible shape. Other raw locals retain layout-based allocation,
raw destinations and resolved reads. Runtime saved-SP/frame-base locals shift
by the omitted PC slot, while the prologue checks and every Return's SP restore
still use the shared existing emitter. Calls, recursion, memory accesses,
volatile order and retained faulting producers are neither removed nor moved
within their blocks.

There is no public API, admission, WASM32 verification, final MVP validation,
optimizer, frontend, native, CLI, general opcode wrapper or conversion-lowering
change. The existing one-return-block path remains supported. No general CFG
structurizer, loop transformation, select speculation or stackification is added.

## Maintained correctness evidence

Five dedicated tests require Node and independently validate generated bytes
with `wasmparser::WasmFeatures::WASM1`. They cover:

- Void, i32 and i64 returns, i64 conditions including nonzero upper bits,
  reversed arm layout, entry/shared aliases and retained raw producers.
- Division traps only on the selected arm, including an aliased retained
  signed division and signed-overflow/zero traps on separate instances.
- Exact-width volatile i64 and unused ordinary i16 loads, pointer truncation,
  complete-memory canaries and stores before/after a selected-arm load trap.
- Recursive address-taken frames, preserved values after recursive calls,
  repeated normal returns, both arms of framed void/i32/i64 functions, and
  allocation exhaustion before body stores. Trapped instances are discarded.
- Removed layout blocks, rejected cross-arm definitions and aliases, unused
  unsupported functions and unused over-aligned static slots.

Eighteen unmatched body snapshots (six shapes in each of scalar, memory and
runtime profiles) were captured by compiling unchanged `a45e1e96` in this
checkout and compared byte for byte with the candidate. Shapes cover parameter
arms, duplicate successors, a nonterminal arm, four layout blocks, switch and
loop phi swaps. Runtime execution independently checks the phi swap result.
The original direct-return test's branch fixture is now eligible: only that
fixture skips its obsolete dispatch snapshot and requires no loop. Its other
12 frozen body comparisons remain intact.

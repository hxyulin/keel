## Source review

The predicate requires exactly three layout blocks, entry first, an entry Brif
to distinct remaining blocks, empty edge arguments and parameterless ordinary
Return arms. It rejects intermediate terminators. Arm emission follows true/false
successor order even when layout order is reversed. The resolved-read scan
admits only entry parameters and definitions already visited in entry or the
current arm; raw destination locals retain layout allocation. Shared entry
aliases, retained faulting producers and removed alias definitions therefore do
not introduce cross-arm reads or replacement-local writes. The real verifier
still rejects malformed and nondominating input before shape selection.

Only the selected arm executes; both arms retain their own instruction order.
The shared condition, call, load/store and Return lowering is unchanged. An
empty-typed MVP if/else plus unreachable continuation supports void/i32/i64
returns without speculative evaluation or result transport. Omitting the PC
local also shifts saved-SP/frame-base indices consistently. The shared prologue
still checks unsigned subtraction and stack bottom before changing SP or running
body effects. Every normal Return restores its saved incoming SP, including both
arms, recursive calls and framed void/integer returns. Traps retain the existing
instance-discard contract.

Public APIs, complete original-input unsupported admission, actual runtime
WASM32 verification, all-function frame preparation and final WASM1 validation
are untouched. No optimizer, frontend, native or CLI changes were made.

## Independent regression and snapshot evidence

The new `tests/terminal_if_review.rs` adds three tests:

- A false-arm retained signed i32 division aliases an earlier arm-local constant
  through a removed definition. Normal results must read the replacement rather
  than the raw quotient. Zero and signed-overflow traps occur only when this
  arm is selected, in scalar, fixed-memory and runtime profiles.
- Entry and selected-arm calls write volatile four-byte markers. Complete-memory
  checks distinguish true-arm return, false-arm normal return, and false-arm
  division failure before a later call. Runtime caller and callee each have real
  frames; repeated calls through both arms leave the next frame at address
  65520. Each trap runs last on its own fresh instance.
- An entry read aliased to a later arm definition must report a dominance failure
  before emission in all three profiles, including without exports.

The candidate's five tests additionally cover void/i32/i64, high i64 condition
bits, reversed layout, volatile/unused ordinary load faults, pointer truncation,
recursive slots/canaries, exhaustion before effects, removed blocks and unused
unsupported input. Valid negative eligibility controls include parameter arms,
duplicate successors, a jumping arm, four blocks, switch and loop phi swaps.
